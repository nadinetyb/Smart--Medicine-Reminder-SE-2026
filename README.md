## Type of Software
PillTime -> Mobile Application

## Project Description
PillTime is a mobile application that reminds patients when to take their medicines. It displays a daily schedule of medicines, including the time and quantity for each dose. It also monitors medicine stock and alerts users when their supply is running low.
